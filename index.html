SOVL Mod Editor

This tool needs the catalog that ships with the game — it lists the units, properties and effects this build understands.

Your browser will not let a page opened from disk read a file next to it, so pick it manually: catalog.v1.json, in this folder or in the game's StreamingAssets/modding.

Serving this folder over http instead — python -m http.server — loads it automatically.
